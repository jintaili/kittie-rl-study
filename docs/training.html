Training reproduction

The intended execution path is pretrained Qwen → behavior cloning → Head Goon PPO. This repository starts with the training update code; standalone training and evaluation integration is in progress.

ComponentCurrent state
BC objective and epochImplemented in head_goon_study.bc. Retains the distinct short-batch normalization of each supervised stage. Caller supplies a loaded actor, weighted tokenized rows and optimizer.
PPO updateOriginal update, KL audit and critic-fitting functions retained in head_goon_study.ppo. Requires the policy interface, fresh completed rollouts and checkpoint writer.
Action readout, scoring, GAEExtracted with original function bodies. Synthetic CPU tests cover conditional actions, accumulation, clipping, frame discounting and terminal-unapplied weighting.
Data and checkpointsHashes and identifiers documented in study.json. Downloadable training assets remain to be packaged.
Model and native game integrationPending: pinned text-weight loader, tokenizer contract, native rollout collector and GPU environment.
Training orchestrationPending: validation, sequential checkpoint and optimizer/RNG restoration, critic initialization, full BC and 16-iteration PPO entry points.

CPU tests validate numerical components only. They do not establish end-to-end equivalence to the historical GPU jobs. New training should reproduce the method; exact weights and real-time trajectories are not guaranteed.

The main narrative treats the supervised stages as one BC phase. For full initialization details see Appendix A. The tiny statistical analysis package stays alongside the paper to make its reported uncertainty and significance tests inspectable.
